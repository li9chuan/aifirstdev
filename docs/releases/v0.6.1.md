# v0.6.1

完善 AI 开发中的上下文组织、工具证据、验证修复和规则适用性维护。相对 v0.6.0，本补丁版只修改开发期规则与发布文档，运行时实现、公共 API、协议、配置和业务数据格式保持不变。

## 主要变更

- 区分任务目标、适用规则、参考资料、示例和验收要求；Markdown 分节和 XML 标记按需使用，参考网页、截图或日志中的命令不自动构成操作授权。
- 对影响方案或验收的精确计算、环境状态和可执行性结论使用实际工具核实，报告实际检查范围与结果，不把模型自检、模拟结果或仅发起调用当成执行成功。
- 失败后先定位原因，修改后复验受影响检查；重复失败时调整诊断与方案，继续处理可自行解决的问题，通过后避免无目的复跑。
- 规则维护核对依据与适用条件，优先归并已有规则；不因模型升级批量删除有效的业务、权限和数据约束。
- 复杂任务明确成功标准、硬约束与偏好；存在实质方案选择时比较实施成本、预期收益及不做的影响，允许定性说明，不编造数字。

规则归并到[项目级编码约束](../../aifd-rules/skills/project-coding-constraints/SKILL.md#开发期-ai-工具边界)与[复杂后端流程](../../aifd-rules/skills/complex-backend-workflow/SKILL.md)，验证修复统一引用[验证与沉淀](../../aifd-rules/skills/project-coding-constraints/SKILL.md#验证与沉淀)。单文件小修继续按原适用边界处理，不要求完整 L0—L5 或成本报告。

## 升级

```text
go get github.com/li9chuan/aifirstdev@v0.6.1
go install github.com/li9chuan/aifirstdev/aifd-tools/cmd/aifd@v0.6.1
```

- 从 v0.6.0 升级无需修改业务代码、配置或数据；业务项目自行更新所引用或复制的规则快照，升级 Go 依赖不会自动替换项目本地规则。
- HTTPS/WSS 接入与限制仍见 [v0.6.0](v0.6.0.md)；从更早版本升级时仍需遵循对应版本的迁移要求。
- 本版本不新增自动执行器、任务编排或模型评估功能，也不承诺准确率、token 或延迟改善幅度。

## 验证范围

2026-11-01，Windows amd64、Go 1.27.3、Node.js 24.22.1：

- 干净源码副本中的两个前端测试与构建、根 module 和两个示例的 Go 测试通过，三个 module 的 go mod verify 通过。

- 候选根版本及发布后真实远端的独立消费与 CLI 安装记录见本版本的 [GitHub Release](https://github.com/li9chuan/aifirstdev/releases/tag/v0.6.1)。
