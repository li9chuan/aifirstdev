# v0.7.0

拆出统一日志入口 `aifd-log`，普通日志改用本地文本，新增以结构体为事件的 CSV Stat，
并完善文件轮转、异常尾部恢复、保留清理和关闭错误报告。修复 HTTP/ACME 停服时重复关闭监听器。

## 主要变更

- 日志门面归 `aifd-log`，Go 包名仍为 `logging`，与框架共享根 module 和版本；不依赖 observe、RPC 或 runtime。普通日志使用标准库 `slog.TextHandler`，Stat 写原始 CSV。
- `User.Stat(payload)` 和 `RecordStat(payload, buildHeader)` 直接接受具名 struct 或非 nil 指针，事件名取结构体名，保留大小写；首次使用校验并缓存字段布局，拒绝不同类型的同名事件。
- 业务通过 `WithStatHeader` 提供完整公共头，回调接收事件名字符串。时间、身份字段、版本演进及消费映射归业务；不要求 feature 注册事件清单。
- `Config.Stat` 提供独立本地 CSV 与可选有界异步转发；先写本地，再把同一成品记录送入远端队列。接收服务、聚合、重试和补录由项目实现，不要求 observe 在线。
- 普通日志和 Stat 各自配置大小、日期、归档保留和 gzip；默认每文件 1 GiB、本地自然日切分、不清理、不压缩。相对路径初始化时固定，关闭等待本地清理 worker 退出。
- 新归档名增加数字时区偏移，例如 `stat-2026-11-12T00-00-00.123+0800.log`，按真实时刻排序和清理；防覆盖检查共用轮转命名函数。兼容旧的不带偏移格式，重复时刻保守取较晚候选。
- Stat 启动先隔离损坏或未以换行结束的 CSV 尾部，保留正常前缀和修改日期；运行期失败追加回退长度与偏移，Windows 重开已有文件也保留截断权限。回退失败后拒绝继续写入与轮转。
- 后台清理和压缩失败写 stderr，首次失败保留到关闭返回；后续重试成功不抹去诊断。observe-agent 兼容新文本与历史 JSON，CSV 按原文查询。
- HTTP、TLS 与 ACME 监听器共享幂等关闭，消除正常停服中的重复关闭误报，并保留首次真实关闭错误；补齐固定触发时序的关闭和重启回归。

## 升级与兼容性

```text
go get github.com/li9chuan/aifirstdev@v0.7.0
go install github.com/li9chuan/aifirstdev/aifd-tools/cmd/aifd@v0.7.0
```

- 将旧日志导入 `github.com/li9chuan/aifirstdev/aifd-observe/logging` 改为 `github.com/li9chuan/aifirstdev/aifd-log`；不保留旧路径 wrapper。
- 旧 `Config.Observe` 改为宿主显式组合 `Config.SecondaryHandler`；需要 observe 时使用 `aifd-observe/adapters/logging.NewHandler`，handler 生命周期由宿主管理。
- 旧字段式 `Stat`、`StatContext`、`Statf`、`StatfContext` 和默认 Sink 入口已移除。typed CSV 需要显式配置 `Config.Stat.LocalPath` 并提供业务公共头；需要观测 envelope 的调用方直接组合 observe 的 `Event` 与 `Sink.Write`。
- 普通日志从 JSON 改为文本；依赖旧 JSON 字段的采集和查询工具需同步适配。Stat CSV 包含标准引号转义和字段内换行，补录应按逻辑记录读取，不能逐物理行处理。
- 事件类型名直接成为数据契约，类型重命名会改变事件名；业务负责更新消费端映射。默认应用头示例为 `Time、EventName、UID`，秒级日期由业务格式化为 `2006-01-02 15:04:05`，框架不自动添加版本列。
- 归档文件名新增时区偏移；按旧格式匹配归档的脚本需适配。旧文件无需批量改名，但无偏移名称仍依赖原时区配置；回拨歧义可能使归档多保留一个回拨时长，数量限制仍独立生效。
- `.corrupt-*` 隔离文件不自动清理、转发或补录，检查与处理归项目。每个日志路径须由单个进程、单个 logger 独占。
- 框架和 CLI 统一升级根 module；本次不自动升级 IOI 或其他业务项目的依赖、规则、协议或部署。

完整配置、故障语义和可执行接线见[日志说明](../../aifd-log/README.md)与 [Typed Stat](../stat.md)。

## 边界

- Write 成功表示写入操作系统，不提供逐条 fsync，也不与业务存储组成事务。
- 可选转发是有界、无自动重试的尽力投递；队列满、超时和远端故障不回退本地记录。
- 启动恢复流式扫描整个活动 CSV，读取量随文件大小增长；不自动补发历史记录。
- 桌面安装器、业务部署、真实断电恢复、Linux 实机运行及公开 CA 长期续期不属于本次框架发布验收。
