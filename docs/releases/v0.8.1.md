# v0.8.1：只读身份解析与离线导入维护

本补丁补齐 v0.8.0 消费接入所需的账号能力，不兼容旧版数据的边界保持不变。

- 新增 Service.ResolveAccount，直接查询受信身份；不调用验证器、不建号、不开会话，禁用账号仍可读。宿主必须授权，不能把查询作为认证。
- 公开 LoginRefFromPrincipal，离线导入复用同一 IndexKey 与 HMAC 身份规则，不再复制内部算法。
- MemoryStore/RedisStore 提供可选 DeleteCreatedAccount，仅清理离线批次新建且身份/revision/epoch/status 未变化的账号。宿主先隔离账号写入者；跨 key 非原子、结果不明不自动重试，支持核实状态后的受控恢复。初始状态不能证明从未登录，不是在线删除 API。
- 不给 Store 或 ServiceAPI 添加必需方法，不改变 v0.8.0 的账号/会话存储格式或网络协议。

验证包含只读无副作用、禁用状态、索引一致、错误目标拒绝、版本变化拒绝、重复清理和 ID 不复用；真实 Redis 8.6.7 standalone/Cluster 的分步故障与 socket 响应丢失验证删除不重放。

发布前已通过账号相关 146 个 race 测试项（含子测试，无跳过），其中包括真实 standalone/Cluster 与响应丢失场景；scripts/verify.ps1 的三个 Go module、两个前端测试和构建通过，配置了真实 NATS 测试入口。协议生成输入/输出未变化，复用 v0.8.0 的生成一致性证据。

真实微信/短信和业务项目接入仍需单独验收；本补丁不提供旧账号自动迁移。
